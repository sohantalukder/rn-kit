# Introduction

`@sohantalukder/rn-kit` is a React Native UI kit with theme primitives,
reusable components, overlay providers, and local SVG icons.

Use this Storybook as the live component workshop and the Next.js docs site as
the package documentation hub.

## Best practices

- Start with `ThemeProvider`.
- Add `UiPortalProvider` when using toast, dialog, bottom sheet, or context menu managers.
- Keep package APIs stable and document every public component as it is exported.

# Installation

```sh
npm install @sohantalukder/rn-kit
```

Install the core React Native peers in the consuming app:

```sh
npm install react-native-gesture-handler react-native-reanimated react-native-safe-area-context react-native-svg
```

`Image`, `Avatar`, `PhotoCarousel`, `BottomSheet`, and the global bottom sheet
manager are implemented inside the package. `Image` uses React Native `Image`,
so FastImage-style native cache controls are not included.

React Navigation is not required by this package. Apps that use React Navigation
can pass `theme.navigationTheme` to their navigator.

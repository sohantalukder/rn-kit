# Installation

```sh
npm install @sohantalukder/rn-kit
```

Install the core React Native peers in the consuming app:

```sh
npm install react-native-gesture-handler react-native-reanimated react-native-safe-area-context react-native-svg @react-navigation/native @react-navigation/stack
```

Feature-specific peers:

- `@d11/react-native-fast-image` for `Image`, `Avatar`, and `PhotoCarousel`.
- `@gorhom/bottom-sheet` for the global bottom sheet portal manager.

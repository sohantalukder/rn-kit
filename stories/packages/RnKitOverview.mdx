# @sohantalukder/rn-kit

A standalone React Native UI package with atoms, molecules, organisms,
templates, theme tokens, local icons, and overlay providers.

## Install

```sh
npm install @sohantalukder/rn-kit
```

## Usage

```tsx
import { ThemeProvider, Button, Text } from '@sohantalukder/rn-kit';

export function Example() {
  return (
    <ThemeProvider>
      <Text variant="heading3">Ready</Text>
      <Button text="Continue" onPress={() => {}} />
    </ThemeProvider>
  );
}
```

## Notes

- The browser Storybook preview uses `react-native-web`.
- Native-only peers are shimmed for documentation previews.
- Verify native behavior in a React Native app before publishing changes.
